Skill should have at least this 9 building blocks: 
👉 When to Use & Triggers — and, just as important, what should NOT trigger it
👉 Workflows & Steps — the stage-by-stage procedures
👉 Scripts & Tools — the executable logic the agent runs
👉 Rules & Guidelines — the non-negotiable guardrails
👉 Error Handling — real failure modes as Error → Cause → Fix
👉 Scenarios & References — the supporting knowledge
👉 Quick Reference — a task → exact command cheat sheet
👉 Collaboration & Iteration Loop — human-in-the-loop + refine on real traces
👉 Output specs, Success, Evaluation & Security

Plus two things which should never be forgot:
👉 The description (USE FOR / DO NOT USE FOR) — this is the single point of failure for whether your skill ever activates
👉 Grounding & context budget — build from real tasks and failures, not generic knowledge, and keep it lean (the spec recommends ≤ 500 lines / 5,000 tokens)
